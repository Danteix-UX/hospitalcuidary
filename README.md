# Hospital Veterinário Cuidary

Landing page responsiva implementada a partir do arquivo HOSPITAL no Figma.

## Executar localmente

```bash
npm install
npm run dev
```

## Gerar a versão de produção

```bash
npm run build
```

Os arquivos finais serão criados em `dist/`.

## Estrutura

- `src/App.jsx`: componentes, conteúdo e interações.
- `src/styles.css`: sistema visual e responsividade.
- `public/assets`: imagens e vetores exportados do Figma.
